# Sổ xuất trứng

Ứng dụng web tĩnh: mở `index.html`. Các file icon và `manifest.webmanifest` được dùng cho favicon và thao tác thêm ứng dụng ra màn hình chính.

Để cài trên iPhone, ứng dụng cần được phục vụ qua HTTPS; mở bằng Safari, chọn **Chia sẻ → Thêm vào Màn hình chính**. GitHub Pages cần được bật riêng trong **Settings → Pages** để có địa chỉ web trực tiếp.
